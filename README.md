# CAFFA CFD代码架构分析

## 项目概述

**项目名称**: CAFFA (Computer Aided Fluid Flow Analysis)  
**版本**: 1.3 (1997年8月)  
**开发者**: M. Peric (汉堡，1996), M. Schmid (汉堡，1997)  
**目的**: 基于有限体积法的CFD求解器，使用SIMPLE算法在共位体拟合网格上求解流动问题

## 核心算法特性

- **数值方法**: 有限体积法 (Finite Volume Method)
- **求解算法**: SIMPLE算法（半隐式压力连接方程）
- **网格类型**: 共位体拟合网格 (colocated body-fitted grids)
- **湍流模型**: k-epsilon湍流模型，带壁面函数（高雷诺数流动）
- **多重网格**: 支持多重网格加速收敛
- **时间格式**: 支持稳态和非稳态计算

## 文件详细说明

### 1. 主程序文件

#### **caffa.f** (66,631 字节)
**作用**: CFD求解器的主程序

**主要功能模块**:
- `PROGRAM CAFFA`: 主程序入口
- 文件I/O管理
- 多重网格循环控制
- 时间步进控制
- SIMPLE迭代循环
- 求解动量方程 (`CALCUV`)
- 求解压力修正方程 (`CALCP`)
- 求解标量方程（能量、湍动能等）(`CALCSC`)
- 结果输出和保存

**执行流程**:
1. 初始化常数和数据 (`SETDAT`, `MODDAT`)
2. 读取问题名称，打开输入/输出文件
3. 初始化网格和变量 (`INIT`)
4. 如需要，读取上次计算结果 (LREAD)
5. 多重网格循环 (DO 500 KGR=KGST+1,NGR)
   - 从粗网格向细网格插值
   - 时间循环 (DO 400 ITIM=ITIMS,ITIME)
     - SIMPLE外迭代循环 (DO LS=1,LSG(KGR))
       - 求解U和V动量方程
       - 求解压力修正方程
       - 求解能量方程（如激活）
       - 求解湍动能方程（如激活）
       - 求解湍流耗散率方程（如激活）
       - 更新湍流粘度
       - 输出残差和监测点数值
6. 保存结果和后处理
7. 关闭文件

#### **user.f** (7,628 字节)
**作用**: 用户自定义子程序

**主要子程序**:

1. **SUBROUTINE BCIN(K)**
   - 设置入口边界条件
   - 读取入口速度、温度、湍动能、耗散率
   - 计算入口质量流率
   - 计算出口平均速度
   - 设置壁面温度（冷壁、热壁、绝热壁）
   - 设置残差归一化因子

2. **SUBROUTINE SOUT(K)**
   - 输出额外的物理量
   - 计算壁面剪切力分布
   - 计算壁面压力分布
   - 计算热流密度分布（等温壁面）

3. **SUBROUTINE TOUT(K)**
   - 非稳态计算的时间步输出
   - 用户可自定义额外输出

这些文件定义全局变量和参数，通过INCLUDE语句包含到主程序中。

**作用**: 定义网格索引和控制变量

**主要变量**:

#### **logic.inc** (241 字节)
**作用**: 定义逻辑控制变量

**主要变量**:
- `LWRITE`: 是否写入结果

- `LTIME`: 非稳态计算
- `LCAL(NFI)`: 各变量是否求解的开关

#### **bound.inc** (604 字节)
**作用**: 定义边界条件相关变量

**主要数组**:

- `IJW, IJPW`: 壁面边界网格点索引

- `GDS(I)`: 离散格式混合因子（0=迎风，1=中心）

## 算法架构

### SIMPLE算法流程

```
1. 猜测压力场 P*
2. 求解动量方程得到速度场 U*, V*
   a₁U₁ + a₂U₂ + ... = b + (P₁ - P₂)S
3. 求解压力修正方程
   ∑(P'ᵢ - P'ⱼ)Dᵢⱼ = ṁ*（质量不平衡）
4. 修正压力和速度
   P = P* + P'
   U = U* - D(P'₁ - P'₂)
5. 求解其他标量方程（T, k, ε）
6. 更新物性（湍流粘度）
7. 检查收敛，否则返回步骤2
```

### k-epsilon湍流模型

**湍动能方程**:
```
∂(ρk)/∂t + ∇·(ρUk) = ∇·[(μ + μₜ/σₖ)∇k] + Pₖ - ρε
```

**耗散率方程**:
```
∂(ρε)/∂t + ∇·(ρUε) = ∇·[(μ + μₜ/σₑ)∇ε] + (C₁Pₖ - C₂ρε)ε/k
```

**湍流粘度**:
```
μₜ = Cμ ρ k²/ε
```

**壁面函数**: 使用标准对数律壁面函数，适用于高雷诺数流动

## 编程语言和标准

- **语言**: Fortran 77/90
- **特点**: 
  - 使用COMMON块共享变量
  - 使用INCLUDE文件组织代码
  - 数组采用静态分配
  - 适合教学和研究用途

## 代码特点和局限

**优点**:
- 结构清晰，易于理解
- 注释详细
- 包含完整的测试案例
- 适合学习CFD算法

**局限**:
- 仅支持2D问题
- 固定数组大小（需重新编译改变网格规模）
- 单处理器串行计算
- 有限的湍流模型选择
- 较旧的编程风格

## 适用问题类型

- 2D稳态/非稳态不可压流动
- 层流或湍流（高雷诺数）
- 传热问题（对流换热）
- 复杂几何（体拟合网格）
- 低马赫数流动
